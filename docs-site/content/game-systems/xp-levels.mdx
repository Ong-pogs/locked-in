# XP & Levels

XP measures how much you've actually completed across Locked In. Your level is
shown on your profile badge in the top bar.

## Earning XP

| Milestone | XP |
|---|---|
| Complete a lesson (first time) | **+100** |
| Complete a module | **+500** |
| Complete a course | **+2,000** |

Each milestone pays **exactly once** — replays, practice runs, and repeat
visits award nothing. XP only ever goes up.

## Levels

| Level | XP required |
|---|---|
| 1 | 0 |
| 2 | 500 |
| 3 | 1,500 |
| 4 | 3,500 |
| 5 | 7,000 |
| 6 | 12,000 |
| 7 | 20,000 |

<Callout type="info">
  XP is **cosmetic**. It doesn't affect yield, the Community Pot, Shields, or
  anything with money attached. It exists so your profile reflects the work
  you've put in — nothing more.
</Callout>
