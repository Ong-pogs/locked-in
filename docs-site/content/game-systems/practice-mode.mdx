# Practice Mode

The **Practice Hall** (the blue-lit chapel in the village) lets you replay
lessons from courses you've **fully completed** — free, forever, with no
stakes.

## How it works

- Only **completed courses** appear in the Practice Hall. Courses you're
  still working through aren't replayable there — your daily loop is for new
  progress.
- Practice attempts are **fully graded** with the same quiz engine, including
  per-question feedback, so it's genuine spaced repetition — not a flashcard
  facsimile.
- Practice writes **nothing**: no streak, no XP, no progress records, no
  effect on yield or the Community Pot. The results screen will tell you
  you're in practice mode.

<Callout type="info">
  Practice Mode is the long-term payoff of finishing a course: you keep the
  material forever. Combined with the Quick Recall checks, it's how Locked In
  supports actually *retaining* what you paid yourself to learn.
</Callout>
