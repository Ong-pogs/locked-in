# The Arena (1v1 Quiz Ladder) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an async 1v1 quiz ladder where players compete on a fixed question set for Elo rating and cosmetic XP, with zero interaction with money, streak, shields, or the Community Pot.

**Architecture:** A standalone `arena` Postgres schema and a `modules/arena` Fastify module, deliberately isolated from the lesson engine (which gates real funds). Pure logic — Elo and scoring — lives in `src/lib/` so it unit-tests without a database. Matches are async: both players get an identical server-fixed question set, play independently inside a 24h window, and the match settles once both submit or at expiry.

**Tech Stack:** Fastify 5 (ESM, `.mjs`), PostgreSQL 16/17 via `pg`, vitest (`unit` + `api` projects), Next.js 16 App Router + Tailwind for the frontend.

**Spec:** `docs/superpowers/specs/2026-09-11-arena-1v1-design.md`

## Global Constraints

- **Isolation contract:** a completed match writes only to `arena.*`, `lesson.user_xp`, and `lesson.user_xp_events`. Never to `lesson.user_course_runtime_state`, `user_lesson_progress`, `user_lesson_attempts`, `completion_vouchers`, `claim_attempts`, `unlock_receipts`, `miss_consequence_receipts`, `harvest_result_receipts`.
- **No money.** No ante, prize, pot interaction, yield, shield, lapse, streak, or leaderboard-weight effect. Ever.
- **MCQ only.** Exactly 3 options per question. No short-text (it routes to the LLM grader — too slow and non-deterministic for a timed race).
- **Answer keys never leave the server** before that player's match is `COMPLETE`. This deliberately inverts the lesson path, which returns `correctAnswer` post-submit at `backend/src/modules/progress/repository.mjs:1390` and `:4622`.
- **Migrations:** next numbers are `0063` and `0064`. `backend/scripts/migrate.mjs` is the ONLY sanctioned SQL executor (ruling R22).
- **Write migration files with LF line endings.** The working copy is `core.autocrlf=true` while the tracker records LF checksums from CI; CRLF files record hashes that permanently disagree with CI.
- **Match shape:** 7 questions, 20s cap each. Elo start 1200, K=32, draw S=0.5. XP: win 50 / draw 25 / loss 10, max 5 XP-earning matches per UTC day. Repeat-opponent K damping `1/n` within a rolling 24h window. Ladder page size 100.
- **Run backend tests with the local binary** (`npx vitest run --project unit`). Note: 3 unit files and the whole `api` project currently fail at HEAD for a pre-existing reason — `backend/scripts/*.mjs` begin with a `#!/usr/bin/env node` shebang that vitest's transform rejects. Task 0 fixes this because the `api` project is otherwise unrunnable.

// backend/src/lib/arenaRating.mjs
// Elo for the arena ladder. Pure — no database, no clock.
export const ARENA_START_RATING = 1200;
export const ARENA_BASE_K = 32;

export function expectedScore(ratingA, ratingB) {
  return 1 / (1 + 10 ** ((ratingB - ratingA) / 400));
}

// Anti-collusion: the nth rated match against the SAME opponent inside the
// rolling window is worth K/n. Two accounts trading wins converge on zero
// gain without penalising a genuine rivalry's first few games.
export function effectiveK(recentMatchesVsSameOpponent) {
  const n = Math.max(0, Math.floor(recentMatchesVsSameOpponent)) + 1;
  return Math.max(1, Math.round(ARENA_BASE_K / n));
}

export function applyElo({ ratingA, ratingB, scoreA, priorMeetings = 0 }) {
  const k = effectiveK(priorMeetings);
  const deltaA = Math.round(k * (scoreA - expectedScore(ratingA, ratingB)));
  // Zero-sum by construction rather than by rounding twice.
  return {
    ratingA: ratingA + deltaA,
    ratingB: ratingB - deltaA,
    deltaA,
    deltaB: -deltaA,
  };
}
```

// backend/src/lib/arenaScoring.mjs
// Pure match scoring. No database, no clock.
export const ARENA_QUESTION_COUNT = 7;
export const ARENA_QUESTION_TIMEOUT_MS = 20_000;

export function clampElapsed(ms) {
  if (!Number.isFinite(ms) || ms < 0) return 0;
  return Math.min(Math.round(ms), ARENA_QUESTION_TIMEOUT_MS);
}

// outcome 'VOID' means: settle the match, change nobody's rating, award no XP.
export function resolveMatch(a, b) {
  // Neither player ever played. The comparator below would call this a
  // legitimate draw and move two people's Elo for a match nobody entered.
  if (a.forfeited && b.forfeited) {
    return { outcome: 'VOID', scoreA: null };
  }
  if (a.correctCount !== b.correctCount) {
    return a.correctCount > b.correctCount
      ? { outcome: 'A', scoreA: 1 }
      : { outcome: 'B', scoreA: 0 };
  }
  if (a.totalMs !== b.totalMs) {
    return a.totalMs < b.totalMs
      ? { outcome: 'A', scoreA: 1 }
      : { outcome: 'B', scoreA: 0 };
  }
  return { outcome: 'DRAW', scoreA: 0.5 };
}
```

import { randomBytes } from 'node:crypto';
import { query, getPool } from '../../lib/db.mjs';
import { badRequest, notFound, conflict } from '../../lib/errors.mjs';
import { ARENA_QUESTION_COUNT } from '../../lib/arenaScoring.mjs';

const MATCH_WINDOW_MS = 24 * 60 * 60 * 1000;
// Crockford-ish: no I/O/0/1, so a code read aloud or typed from a screenshot
// does not turn into a different match.
const CODE_ALPHABET = 'ABCDEFGHJKMNPQRSTUVWXYZ23456789';

function newJoinCode() {
  const bytes = randomBytes(8);
  return Array.from(bytes, (b) => CODE_ALPHABET[b % CODE_ALPHABET.length]).join('');
}

async function drawQuestionIds(client, walletAddress) {
  // Prefer questions this wallet has not seen; top up with random actives if
  // the bank is exhausted for them.
  const result = await client.query(
    `with seen as (
       select distinct question_id from arena.match_answers where wallet_address = $1
     )
     select q.id from arena.questions q
      where q.active
      order by (q.id in (select question_id from seen)) asc, random()
      limit $2`,
    [walletAddress, ARENA_QUESTION_COUNT],
  );
  if (result.rowCount < ARENA_QUESTION_COUNT) {
    throw badRequest('Arena question bank is too small to start a match', 'ARENA_BANK_EMPTY');
  }
  return result.rows.map((r) => r.id);
}

export async function createLinkMatch(walletAddress) {
  const pool = getPool();
  const client = await pool.connect();
  try {
    await client.query('begin');
    const questionIds = await drawQuestionIds(client, walletAddress);
    const inserted = await client.query(
      `insert into arena.matches (join_code, origin, status, creator, question_ids, expires_at)
       values ($1, 'link', 'OPEN', $2, $3, now() + interval '24 hours')
       returning id, join_code as "joinCode", expires_at as "expiresAt"`,
      [newJoinCode(), walletAddress, questionIds],
    );
    await client.query(
      `insert into arena.match_players (match_id, wallet_address) values ($1, $2)`,
      [inserted.rows[0].id, walletAddress],
    );
    await client.query('commit');
    return { matchId: inserted.rows[0].id, joinCode: inserted.rows[0].joinCode, expiresAt: inserted.rows[0].expiresAt };
  } catch (err) {
    await client.query('rollback');
    throw err;
  } finally {
    client.release();
  }
}

export async function joinMatchByCode(walletAddress, joinCode) {
  const pool = getPool();
  const client = await pool.connect();
  try {
    await client.query('begin');
    const found = await client.query(
      `select id, creator, opponent, status from arena.matches
        where join_code = $1 for update`,
      [String(joinCode).toUpperCase()],
    );
    if (found.rowCount === 0) throw notFound('Challenge not found', 'ARENA_MATCH_NOT_FOUND');
    const match = found.rows[0];
    if (match.creator === walletAddress) throw badRequest('You cannot join your own challenge', 'ARENA_SELF_JOIN');
    if (match.opponent) throw conflict('This challenge already has an opponent', 'ARENA_MATCH_FULL');
    if (match.status !== 'OPEN') throw conflict('This challenge is no longer open', 'ARENA_MATCH_CLOSED');

    await client.query(
      `update arena.matches set status = 'ACTIVE', opponent = $2 where id = $1`,
      [match.id, walletAddress],
    );
    await client.query(
      `insert into arena.match_players (match_id, wallet_address) values ($1, $2)`,
      [match.id, walletAddress],
    );
    await client.query('commit');
    return { matchId: match.id };
  } catch (err) {
    await client.query('rollback');
    throw err;
  } finally {
    client.release();
  }
}

export async function getMatchState(walletAddress, matchId) {
  const result = await query(
    `select m.id as "matchId", m.status, m.origin, m.join_code as "joinCode",
            m.creator, m.opponent, m.expires_at as "expiresAt", m.resolved_at as "resolvedAt",
            array_length(m.question_ids, 1) as "questionCount"
       from arena.matches m
      where m.id = $1 and (m.creator = $2 or m.opponent = $2)`,
    [matchId, walletAddress],
  );
  if (result.rowCount === 0) throw notFound('Match not found', 'ARENA_MATCH_NOT_FOUND');
  const players = await query(
    `select wallet_address as "walletAddress", started_at as "startedAt",
            submitted_at as "submittedAt", correct_count as "correctCount",
            total_ms as "totalMs", forfeited
       from arena.match_players where match_id = $1`,
    [matchId],
  );
  const match = result.rows[0];
  // Scores stay hidden until the match resolves, so neither player can read
  // the other's result and decide whether it is worth playing.
  const resolved = match.status === 'COMPLETE' || match.status === 'EXPIRED';
  return {
    ...match,
    players: players.rows.map((p) => (resolved ? p : {
      walletAddress: p.walletAddress,
      startedAt: p.startedAt,
      submittedAt: p.submittedAt,
    })),
  };
}

import { clampElapsed, ARENA_QUESTION_TIMEOUT_MS } from '../../lib/arenaScoring.mjs';

function publicQuestion(row, order) {
  // Deliberately omits correct_option_id. The lesson engine reveals its key
  // post-submit (progress/repository.mjs:1390); arena questions are reused
  // across matches, so the key must never ship.
  return {
    id: row.id,
    order,
    prompt: row.prompt,
    options: row.options,
    timeoutMs: ARENA_QUESTION_TIMEOUT_MS,
  };
}

async function assertPlayer(client, matchId, walletAddress) {
  const r = await client.query(
    `select m.id, m.status, m.question_ids as "questionIds", m.expires_at as "expiresAt",
            p.started_at as "startedAt", p.submitted_at as "submittedAt"
       from arena.matches m
       join arena.match_players p on p.match_id = m.id and p.wallet_address = $2
      where m.id = $1 for update of m`,
    [matchId, walletAddress],
  );
  if (r.rowCount === 0) throw notFound('Match not found', 'ARENA_MATCH_NOT_FOUND');
  const row = r.rows[0];
  if (new Date(row.expiresAt).getTime() < Date.now()) {
    throw conflict('This match has expired', 'ARENA_MATCH_EXPIRED');
  }
  return row;
}

async function serveNext(client, matchId, walletAddress, questionIds) {
  const answered = await client.query(
    `select question_id from arena.match_answers where match_id = $1 and wallet_address = $2`,
    [matchId, walletAddress],
  );
  const done = new Set(answered.rows.map((r) => r.question_id));
  const nextId = questionIds.find((id) => !done.has(id));
  if (!nextId) return { question: null, answered: done.size, total: questionIds.length };

  const q = await client.query(
    `select id, prompt, options from arena.questions where id = $1`, [nextId],
  );
  // Server-stamped serve time — the client's clock is never trusted.
  await client.query(
    `insert into arena.match_answers
       (match_id, wallet_address, question_id, question_order, served_at, is_correct, elapsed_ms)
     values ($1,$2,$3,$4, now(), false, 0)
     on conflict (match_id, wallet_address, question_id) do nothing`,
    [matchId, walletAddress, nextId, questionIds.indexOf(nextId) + 1],
  );
  return {
    question: publicQuestion(q.rows[0], questionIds.indexOf(nextId) + 1),
    answered: done.size,
    total: questionIds.length,
  };
}

// backend/src/modules/arena/settle.mjs
import { applyElo, ARENA_START_RATING } from '../../lib/arenaRating.mjs';
import { resolveMatch } from '../../lib/arenaScoring.mjs';
import { awardXp, ensureUserXp } from '../../lib/xp.mjs';

const XP_WIN = 50, XP_DRAW = 25, XP_LOSS = 10;
const XP_DAILY_MATCH_CAP = 5;

async function ratingFor(client, wallet, season) {
  await client.query(
    `insert into arena.ratings (wallet_address, season) values ($1,$2) on conflict do nothing`,
    [wallet, season],
  );
  const r = await client.query(
    `select rating from arena.ratings where wallet_address=$1 and season=$2`, [wallet, season]);
  return r.rows[0]?.rating ?? ARENA_START_RATING;
}

async function priorMeetings(client, a, b) {
  const r = await client.query(
    `select count(*)::int n from arena.matches
      where resolved_at > now() - interval '24 hours'
        and ((creator=$1 and opponent=$2) or (creator=$2 and opponent=$1))
        and status = 'COMPLETE'`, [a, b]);
  return r.rows[0].n;
}

async function xpEarningMatchesToday(client, wallet) {
  const r = await client.query(
    `select count(*)::int n from lesson.user_xp_events
      where wallet_address=$1 and source like 'arena_%'
        and created_at >= date_trunc('day', now() at time zone 'utc')`, [wallet]);
  return r.rows[0].n;
}

// Returns true if this call is the one that settled the match. Concurrent
// callers lose the race on arena.rating_events' unique (match_id, wallet).
// Caller owns the transaction.
export async function maybeSettleMatch(client, matchId) {
  const m = await client.query(
    `select id, creator, opponent, season, status
       from arena.matches where id = $1 for update`, [matchId]);
  if (m.rowCount === 0) return false;
  const match = m.rows[0];
  if (match.status === 'COMPLETE' || match.status === 'EXPIRED') return false;
  if (!match.opponent) return false;

  const ps = await client.query(
    `select wallet_address as "walletAddress", submitted_at as "submittedAt",
            coalesce(correct_count, 0) as "correctCount",
            coalesce(total_ms, 0) as "totalMs", forfeited
       from arena.match_players where match_id = $1`, [matchId]);
  if (ps.rowCount < 2) return false;
  // Not finished and not expired yet — nothing to do.
  if (ps.rows.some((p) => !p.submittedAt && !p.forfeited)) return false;

  const a = ps.rows.find((p) => p.walletAddress === match.creator);
  const b = ps.rows.find((p) => p.walletAddress === match.opponent);
  const { outcome, scoreA } = resolveMatch(a, b);

  if (outcome === 'VOID') {
    await client.query(
      `update arena.matches set status='EXPIRED', resolved_at=now() where id=$1`, [matchId]);
    return true;
  }

  const [ra, rb] = [
    await ratingFor(client, a.walletAddress, match.season),
    await ratingFor(client, b.walletAddress, match.season),
  ];
  const meetings = await priorMeetings(client, a.walletAddress, b.walletAddress);
  const elo = applyElo({ ratingA: ra, ratingB: rb, scoreA, priorMeetings: meetings });

  // The unique (match_id, wallet_address) here is the idempotency guard: a
  // concurrent second settle raises and rolls the whole transaction back.
  for (const [wallet, before, after, delta] of [
    [a.walletAddress, ra, elo.ratingA, elo.deltaA],
    [b.walletAddress, rb, elo.ratingB, elo.deltaB],
  ]) {
    await client.query(
      `insert into arena.rating_events (match_id, wallet_address, rating_before, rating_after, delta)
       values ($1,$2,$3,$4,$5)`, [matchId, wallet, before, after, delta]);
    await client.query(
      `update arena.ratings set rating=$3, games=games+1, updated_at=now(),
              wins  = wins   + case when $4 > 0 then 1 else 0 end,
              losses= losses + case when $4 < 0 then 1 else 0 end,
              draws = draws  + case when $4 = 0 then 1 else 0 end
        where wallet_address=$1 and season=$2`, [wallet, match.season, after, delta]);
  }

  for (const [wallet, score] of [[a.walletAddress, scoreA], [b.walletAddress, 1 - scoreA]]) {
    if ((await xpEarningMatchesToday(client, wallet)) >= XP_DAILY_MATCH_CAP) continue;
    await ensureUserXp(client, wallet);
    const [amount, source] = score === 1 ? [XP_WIN, 'arena_win']
      : score === 0.5 ? [XP_DRAW, 'arena_draw'] : [XP_LOSS, 'arena_loss'];
    await awardXp(client, wallet, amount, source, matchId);
  }

  await client.query(
    `update arena.matches set status='COMPLETE', resolved_at=now() where id=$1`, [matchId]);
  return true;
}
